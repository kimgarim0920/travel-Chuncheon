# 춘천 여행지 추천 프로그램
사용자가 원하는 여행 스타일을 선택하면 가장 적합한 춘천 여행지를 추천해주는 키워드 기반 여행 추천 프로그램입니다.
## 프로그램 역할
이 프로그램은 사용자가 원하는 여행 키워드를 선택하면, 미리 저장된 춘천 여행지 데이터와 비교하여 가장 적합한 여행지를 추천합니다.
선택 가능한 키워드는 다음과 같습니다.
- 자연
- 힐링
- 감성 카페
- 맛집
- 체험
- 관광지

사용자가 한 개 이상의 키워드를 선택하면 각 여행지와의 일치도를 계산하여 추천 순위를 정합니다.
동일한 점수의 여행지가 있을 경우 여행지 이름을 가나다순으로 정렬하여 추천합니다.
## 사용 방법
1. 프로그램을 실행합니다.
2. 원하는 여행 키워드를 하나 이상 선택합니다.
3. **춘천 여행지 추천받기** 버튼을 클릭합니다.
4. 선택한 키워드와 가장 잘 맞는 춘천 여행지가 표시됩니다.
5. **다른 여행지 추천받기** 버튼을 클릭하면 선택한 키워드에 속하는 다음 순위의 여행지를 확인할 수 있습니다.
## 유의사항
- 키워드를 선택하지 않으면 프로그램이 작동하지 않습니다.
- 모든 추천 여행지를 확인하면 안내 메세지가 출력됩니다.
## 프로그램 특징
- 다중 키워드 선택 가능
- 키워드 일치도 기반 추천
- 다시 추천 기능 제공
- 춘천 관광지 데이터 기반 추천 시스템
